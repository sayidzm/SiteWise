# Project Brief

Workout Tracker; 15 yaş için tanımlanmış Upper/Lower programını bozmadan, spor salonunda telefondan hızlı set kaydı sağlayan offline-first web app'tir.

Core stack: HTML5 + CSS3 + Vanilla JavaScript + LocalStorage + Service Worker/PWA.

Core loop: Today → Start/Resume → Previous → KG/Reps/RIR → Complete Set → Rest → Finish → History → Progress.

Non-negotiables: mobile-first, real data only, no frameworks, program source immutable unless user explicitly changes it, technique > weight.
